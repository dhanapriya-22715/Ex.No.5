## Types of Prompting Techniques
### 1. Basic Prompting
Definition

Basic prompting involves giving a short and direct instruction to the AI without additional context or examples.

Characteristics
Simple and quick
Minimal instructions
Suitable for straightforward tasks
Limited detail in output
Example

“Explain Artificial Intelligence.”

### 2. Zero-Shot Prompting
Definition

Zero-shot prompting asks the AI to perform a task without providing any prior examples.

Characteristics
No training examples included
Relies on the AI’s pre-trained knowledge
Better than basic prompts when instructions are clear
Example

“Explain Artificial Intelligence in simple language for school students.”

### 3. Few-Shot Prompting
Definition

Few-shot prompting provides a few examples before asking the AI to perform the task.

Characteristics
Demonstrates expected response style
Improves consistency
Produces more structured outputs
Enhances creativity and formatting
Example

Providing 2–3 examples before asking the actual question.

### 4. Chain-of-Thought Prompting
Definition

Chain-of-Thought prompting encourages the AI to solve problems step by step before generating the final answer.

Characteristics
Produces logical reasoning
Generates detailed explanations
Useful for analytical and educational tasks
Improves problem-solving ability
Example

“Explain step by step how Artificial Intelligence work



# Activity 1 – Educational Explanation

# Task

Explain Artificial Intelligence using different prompting methods.


# A. Basic Prompt

## Prompt

> “Explain Artificial Intelligence.”

## Output

Artificial Intelligence (AI) is a technology that enables machines to perform tasks that normally require human intelligence, such as learning, reasoning, and decision-making.

## Analysis

* Response is short and direct.
* Limited detail and explanation.
* Suitable for quick understanding.



# B. Zero-Shot Prompt

## Prompt

> “Explain Artificial Intelligence in simple language for school students.”

## Output

Artificial Intelligence is when computers or machines are designed to think and learn like humans. Examples include voice assistants, robots, and self-driving cars.

## Analysis

* Better clarity compared to the basic prompt.
* Audience-specific explanation improves understanding.
* More user-friendly and contextual.



# C. Few-Shot Prompt

## Prompt

Example 1:
Question: Explain the Internet.
Answer: The Internet is a global network that connects computers and allows people to share information.

Example 2:
Question: Explain Cloud Computing.
Answer: Cloud computing allows users to store and access data through the internet instead of a personal computer.

Now explain Artificial Intelligence in a similar way.

## Output

Artificial Intelligence is a technology that allows machines to think, learn, and solve problems like humans. AI is used in chatbots, virtual assistants, healthcare systems, and smart devices.

## Analysis

* Response follows the structure of provided examples.
* More organized and informative.
* Better consistency and formatting.



# D. Chain-of-Thought Prompt

## Prompt

> “Explain Artificial Intelligence step by step by first defining intelligence, then explaining how machines imitate human thinking, and finally provide examples.”

## Output

1. Intelligence refers to the ability to learn, understand, and solve problems.
2. Artificial Intelligence means creating machines that imitate human intelligence.
3. These systems use algorithms and data to make decisions.
4. AI can recognize speech, analyze images, and solve complex problems.
5. Examples include virtual assistants, recommendation systems, and self-driving cars.
6. Therefore, AI enables machines to perform tasks that usually require human thinking.

## Analysis

* Produces the deepest explanation.
* Logical step-by-step reasoning.
* Best for learning and educational purposes.

# Activity 3 – Problem Solving Scenario

# Task

Solve a mathematical word problem using different prompts.

## Problem

“A shopkeeper buys a pen for ₹20 and sells it for ₹25. Find the profit percentage.”

---

# A. Basic Prompt

## Prompt

> “Find the profit percentage.”

## Output

Profit = ₹5
Profit Percentage = 25%

## Analysis

* Gives only direct answer.
* Minimal explanation.



# B. Zero-Shot Prompt

## Prompt

> “Calculate the profit percentage for a pen bought at ₹20 and sold at ₹25.”

## Output

Cost Price = ₹20
Selling Price = ₹25
Profit = ₹5

\text{Profit Percentage} = \frac{5}{20} \times 100 = 25%

Therefore, the profit percentage is 25%.

## Analysis

* Clearer explanation.
* Better mathematical presentation.


# C. Few-Shot Prompt

## Prompt

Example:
If Cost Price = ₹50 and Selling Price = ₹60
Profit = ₹10
Profit Percentage = 20%

Now solve: Cost Price = ₹20 and Selling Price = ₹25.

## Output

Cost Price = ₹20
Selling Price = ₹25
Profit = ₹5

\text{Profit Percentage} = \frac{5}{20} \times 100 = 25%

Hence, the profit percentage is 25%.

## Analysis

* Follows example structure accurately.
* Consistent formatting.

---

# D. Chain-of-Thought Prompt

## Prompt

> “Solve step by step by calculating cost price, selling price, profit, and then profit percentage.”

## Output

1. Cost Price = ₹20
2. Selling Price = ₹25
3. Profit = Selling Price − Cost Price = ₹5

\text{Profit Percentage} = \frac{5}{20} \times 100 = 25%

4. Therefore, the shopkeeper gains a profit of 25%.

## Analysis

* Best reasoning process.
* Easy to understand for students.
* Highly educational.

# Detailed Analysis


# Basic Prompt Analysis

## Advantages

* Fast and simple
* Suitable for quick responses
* Easy to create

## Disadvantages

* Limited detail
* Lower creativity
* Weak reasoning ability

## Best Used For

* Simple factual questions
* Quick tasks



# Zero-Shot Prompt Analysis

## Advantages

* Better contextual understanding
* No examples needed
* Faster prompt creation

## Disadvantages

* Output quality depends heavily on prompt clarity
* May produce inconsistent structure

## Best Used For

* General-purpose tasks
* Everyday AI interactions


# Few-Shot Prompt Analysis

## Advantages

* Highly structured responses
* Better consistency
* Improved creativity

## Disadvantages

* Requires carefully designed examples
* Longer prompts

## Best Used For

* Content generation
* Formatting tasks
* Structured explanations


# Chain-of-Thought Prompt Analysis

## Advantages

* Strong logical reasoning
* Detailed explanations
* Better analytical capability

## Disadvantages

* Longer responses
* Increased processing time

## Best Used For

* Mathematics
* Problem solving
* Educational applications
* Logical analysis

# Findings

1. Prompt refinement significantly improves response quality.

4. Few-shot prompting improves formatting and consistency through examples.
